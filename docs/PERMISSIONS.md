# Permissions & Narrative Security

## Objetivo
Preservar segredo narrativo em um mundo compartilhado.

## Visibility inicial
- PUBLIC
- PLAYER
- CHRONICLE_ST
- NETWORK_ST
- COORDINATOR
- RESTRICTED

Esses níveis são ponto de partida, não substituem políticas detalhadas de membership/ownership.

## Princípios
1. Authorization antes de retrieval.
2. UI hiding não é segurança.
3. IA não recebe segredos desnecessários.
4. Cross-chronicle discovery deve revelar oportunidade sem necessariamente revelar segredo.
5. Toda elevação/compartilhamento sensível deve ser auditável.
6. Controle de NPC e direito de visualizar/usar NPC são conceitos diferentes.
7. Public Profile deve consumir apenas campos explicitamente publicáveis.

## Futuro
Definir RBAC + ABAC: papéis (player/ST/coordinator/admin) combinados com atributos como Home Chronicle, ownership/control, office, relationship, request authorization e visibility.
