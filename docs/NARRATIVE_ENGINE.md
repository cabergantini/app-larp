# Narrative Engine

## Princípio
Event Truth, Character Knowledge e Rumor são entidades distintas.

## Scene
Cena pode ser registrada por jogador ou ST e receber texto/log/arquivo. Participantes, data, local IC, crônica, fonte e visibilidade devem ser preservados.

## Scene Intelligence
Pode sugerir:
- fatos;
- informações adquiridas;
- relações alteradas;
- promessas/boons;
- rumores potenciais;
- alterações mecânicas;
- ganchos;
- progressão de plot.

Todas são proposals até revisão.

## Character Knowledge
Conhecimento deve registrar subject, claim, knower, source/provenance, confidence/reliability quando apropriado, visibility e temporalidade.

## Rumor
Rumor não implica verdade. Deve poder circular independentemente do Event Truth e registrar origem/proveniência quando conhecida.

## Character Memory
Permite reconstruir encontros, conhecimentos, pendências, relações e histórico relevante para preparação de cenas.

## Chronicle Memory
Permite resumos baseados em registros autorizados: movimentos recentes, plots, NPCs mencionados, pendências e continuidade.

## Privacy
Um resumo por IA só pode utilizar dados que o solicitante esteja autorizado a acessar.
