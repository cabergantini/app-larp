# Functional Specifications

As specs detalham comportamento por domínio e complementam o PRD.

Diretórios planejados:
- character/
- chronicle/
- npcs/
- scenes/
- rules/
- approvals/
- world/
- publishing/

Cada spec deve incluir objetivo, atores, permissões, fluxos, estados, validações, provenance, auditabilidade, critérios de aceite e casos de erro.
