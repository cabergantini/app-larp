# OWBN Narrative Platform

Plataforma de continuidade narrativa para mundos compartilhados de LARP, inicialmente orientada às crônicas brasileiras da One World by Night (OWBN).

> A plataforma não existe para guardar fichas. Ela existe para fazer histórias continuarem.

## Estado
Fase de descoberta, arquitetura de produto e especificação. Não iniciar implementação do produto antes de o PRD e as especificações MVP estarem aprovados.

## Ciclo central
PLAY → RECORD → UNDERSTAND → APPROVE → REMEMBER → CONNECT → PLAY AGAIN

## Regra de ouro
IA sugere; humanos decidem. Nenhuma inferência de IA altera automaticamente ficha, cânone, XP, aprovação, conhecimento ou consequência narrativa.
